# Neue-Konzepte-Gruppe-9
Ein Repsitory, welches für die Vorlesung "Neue Konzepte" erstellt wurde und die Ergebnisse der Gruppe 9 enthält

Ziel ist es, ein Jupyter Notebook zu verfassen, welches die noch ausstehenden Anforderungen erfüllt (Note 2) und übertrifft (Note 1).

Der verwendete Datensatz ist [hier](https://www.kaggle.com/datasets/sunilthite/llm-detect-ai-generated-text-dataset) zu finden. Er enthält über 27k Einträge, die jeweils als KI generiert oder von Menschen geschrieben gekennzeichnet sind. 40% der Daten sind KI generiert.
